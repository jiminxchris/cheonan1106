# 2026 천안시 청년정책 웹 프레젠테이션

## 구성
- `index.html`: 서버 없이 열 수 있는 반응형 인터랙티브 프레젠테이션
- `assets/slide-01.jpg` ~ `slide-10.jpg`: 업로드된 PPTX의 원본 디자인을 고해상도로 렌더링한 이미지

## GitHub Pages 게시
1. ZIP을 압축 해제하여 모든 파일과 `assets` 폴더를 GitHub 저장소 루트에 업로드합니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택하고 `main` / `/(root)`를 지정합니다.
3. Pages 주소에 접속하면 바로 실행됩니다. 별도 빌드, 서버, 데이터베이스가 필요하지 않습니다.

## 조작법
- 이전/다음 버튼, 좌측 목차, 상단 목차 버튼
- 키보드 ←/→, PageUp/PageDown, Space, Home/End
- 슬라이드 위 마우스 휠 및 모바일 좌우 스와이프
- 전체화면 버튼 또는 `F`, `I`로 슬라이드 설명 표시
- 해시 주소 `#slide-5`처럼 특정 페이지 바로 열기

## 참고
원본 PPTX 10장의 이미지·배치·문구를 유지하기 위해 슬라이드 자체는 웹용 이미지로 표시합니다. 따라서 슬라이드 안의 그래프나 텍스트는 HTML 요소로 개별 편집되지 않습니다. 상세 내용 패널에는 읽을 수 있는 텍스트 설명이 포함되어 있습니다. 원본 자료의 기준일은 2026-11-06이며 정책 조건은 해당 사업 공식 공고를 확인하세요.
